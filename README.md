# 어디쌤 — 역할별 파일 분리판

기존 기능·디자인·교사 데이터를 유지한 정적 웹사이트입니다. 설치나 빌드 명령은 없습니다.

## 폴더 구조
- index.html: 화면의 기본 구조, 버튼·검색·안내 영역
- css/styles.css: 색상, 테마, 배치, 워터마크, 도면 강조 효과
- js/data/teachers.js: 선생님 명단과 시간표
- js/data/floorplans.js: 층별 도면 파일 경로·크기
- js/config.js: 교시 시간, 교실 좌표, 과목명, 기본 자리
- js/prepare.js: 공통 도구, 기본 자리 예외 적용, 과목 소개 생성
- js/location.js: 동아리 자료, 수업·기본 위치 계산, 근무 요일
- js/time.js: 현재 한국 시간과 지정 시간 처리
- js/render.js: 선생님 목록·상세·도면·시계 표시
- js/events.js: 검색, 층 선택, 홈, 뒤로 가기, 시간 조회, 자동 갱신
- images/: 도면과 로고 이미지

## GitHub 업로드
1. 현재 사이트를 먼저 백업하세요.
2. 이 폴더 안 index.html, css, js, images를 기존 index.html이 있는 저장소 위치에 함께 올립니다.
3. 폴더 구조와 파일명을 유지하세요. HTML만 올리면 작동하지 않습니다.
4. 기존 Vercel 연동이 있다면 GitHub 변경 후 배포 완료를 확인하세요.
5. 실제 웹 주소에서 로고·도면·검색·시간 조회·뒤로 가기를 확인하세요.

HTML에서는 의존 순서대로 일반 스크립트를 불러옵니다. 순서를 바꾸거나 async를 붙이지 마세요.
분리판은 file:// 직접 열기보다 웹에 배포해 확인하는 것을 권장합니다.
이미지 경로는 index.html 기준 상대 경로입니다. GitHub Pages 하위 경로도 사용할 수 있습니다.

## 유지보수 참고
기존 CSS의 덮어쓰기 규칙은 시각적 변경을 피하려고 그대로 유지했습니다.
기본 자리 보정은 prepare.js에서 적용되므로 config.js 기본값만 수정하면 보정 규칙이 우선할 수 있습니다.
정종민 선생님 개별 미술실 등 수업 예외는 prepare.js의 TEACHING_ROOM에서 관리합니다.
조회 전용이며 Firebase 공용 저장 기능은 포함되지 않습니다.

스크립트 분리 전후 실행 순서와 내용 보존, 문법, 파일 경로·이미지 유효성, 주요 위치 계산 검사.
